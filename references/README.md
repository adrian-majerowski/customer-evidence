# Complete evidence-first method

These are the complete specialist modules for the Customer Evidence skill. The root `SKILL.md` is a router and must direct the agent here before it performs the relevant work.

| Module | Use it for |
| --- | --- |
| `00_evidence_first_product_researcher.md` | Canonical parent methodology for all substantial customer-evidence work. |
| `01_extract_reported_experiences.md` | Context-preserving evidence episodes, evidence readiness, and independence. |
| `02_synthesize_user_problems.md` | Audited synthesis, problem boundaries, null outcomes, and disconfirming cases. |
| `03_followup_research.md` | Non-leading follow-up and interview design. |
| `04_observation_recommendations.md` | Observation plans for behavioral unknowns. |
| `05_research_quality_audit.md` | Method and evidence quality audit. |
| `06_netnographic_context.md` | Community discourse, sampling, norms, and social amplification. |
| `07_constant_comparison.md` | Case comparison, split/merge discipline, and delayed quantification. |
| `08_research_frame.md` | Research question, corpus, population, boundaries, and known limits. |
| `09_next_research_action.md` | Select the next method from the actual decision-relevant unknown. |
| `10_coding_stability_check.md` | Fresh-pass stability check before stabilization. |
| `11_plain_language_research_communication.md` | Accurate, actionable communication for non-researchers. |
| `12_solution_evaluation.md` | Evaluate a solution after the relevant problem is understood. |
| `13_customer_input_quality.md` | Diagnose recurring weakness in feedback collection. |
| `14_research_methodology_reasoning.md` | Method choice, survey and interview reasoning, and inference limits. |
| `15_collection_improvement_agent.md` | Bounded, versioned repair of a demonstrated collection-quality failure. |
