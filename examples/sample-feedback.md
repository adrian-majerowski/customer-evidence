# Synthetic sample: checkout feedback

This example is fictional. It is included only to show the kind of source context that helps the skill distinguish reports, requests, and opinions.

## Research scope

Question: What can the following feedback tell us about customers who abandon checkout after trying a discount code?

Product version: Web checkout v3.2. Time window: 2026-10-01 to 2026-10-15.

## Records

| ID | Source | Date | Context | Customer material |
| --- | --- | --- | --- | --- |
| `S-104` | Support ticket | 2026-10-03 | Customer attempted checkout on desktop. | “I entered the welcome code from your email. It said invalid, so I removed the items and bought from another shop. Please add Apple Pay.” |
| `S-107` | Support ticket | 2026-10-04 | Customer attached a screenshot of `SAVE10` marked invalid. | “This was the first time I tried to order. I had not created an account yet, and the code would not work.” |
| `C-21` | Community post | 2026-10-07 | Thread started after a release announcement. | “Discounts never work here. You should replace the whole checkout.” |
| `S-119` | Support ticket | 2026-10-10 | Returning customer, mobile web. | “The code field was hidden until I expanded the order summary. I assumed there was no place to enter it, so I paid full price.” |
| `S-121` | Support ticket | 2026-10-12 | Same customer as `S-119`, follow-up after support replied. | “I found the field after your instructions. My code worked.” |
| `F-18` | Feedback form | 2026-10-14 | One open text field; no follow-up. | “Add Klarna and fix promo codes.” |

## What this material can and cannot establish

The material contains several first-hand reports of friction around a code at checkout, but the episodes describe different mechanisms: an invalid code, a hidden code field, and an ungrounded general complaint. It does not establish how frequent either mechanism is, whether the `SAVE10` code was actually valid for those customers, whether people generally abandon checkout, or whether any payment method would solve the reported friction.
