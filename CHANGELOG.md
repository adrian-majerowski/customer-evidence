# Changelog

## 1.3.0 — 2026-11-13

- Rewrote the default behavior around short, direct, consequence-first patterns and everyday conversational English.
- Added a behind-the-scenes source-quality card per displayed pattern: first-hand, partial, request-only, or linked discussion; show details only on request.
- Added a mandatory time/version check before combining incidents across product states.
- Clarified episode-level counting in long threads and that customer probability claims are unverified.
- Made the invitation contextual, and made the first post-opt-in reply provide a specific existing-source check plus one neutral prompt for each requested pattern.
- Added more demanding acceptance checks, updated chat fallbacks, and a separate reproducible benchmark kit (no real feedback in the skill ZIP).
- **No live model A/B results are claimed** unless the benchmark is actually run and scored.


## 1.2.0 — 2026-11-13

- Made the default response a short, source-linked **what feedback shows → candidate patterns → what's missing → invitation to dig deeper** conversation.
- Added explicit opt-in, one-pattern-at-a-time discovery with cheap existing-evidence checks before new research.
- Added a specialist for Discord-like scraped exports: bot relays, nested embeds/form fields, thread linkage, deduplication, prompted answers, reactions, version/time boundaries, and privacy.
- Scoped full synthesis/stability work to established findings and requested deep dives, not provisional first-pass pattern scans.
- Refined parent method, plain-language communication, and method-choice timing for conversational output; preserved evidence rigor.
- Added synthetic conversation example and acceptance-test cases; updated chat prompts and regenerated bundled method library.
- Kept the original license and attribution. **No production benchmark or direct A/B model evaluation is claimed.**

## 1.1.2 — 2026-11-13

- Clarified the required folder rename when installing from GitHub's automatic source ZIP.

## 1.1.1 — 2026-11-13

- Linked every specialist module from the root skill and mapped legacy "invoke" names to bundled references.

- Clarified that a chat without the library cannot claim to apply the complete method.
- Matched the skill name and installation folder to the published `customer-evidence` repository.

- Made the root skill route analysis to the required method modules instead of relying on a condensed summary.

## 1.0.0 — 2026-11-13
